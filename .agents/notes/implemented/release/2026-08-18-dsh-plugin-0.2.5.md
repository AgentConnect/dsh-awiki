# dsh-plugin 0.2.5 formal release

## Scope

- Release Web UI group creation with a name and 1–50 initial Handle or DID members through the Rust IM Core `0.1.4` facade.
- Preserve group titles, Direct display names, and group-sender labels through local Core presentation data and identity-scoped browser projections.
- Reconcile optimistic sends by exact client message ID, keep background refresh failures quiet while local content remains usable, and retain the local-first conversation timeline.
- Cache verified image previews in bounded browser-runtime, identity-scoped IndexedDB, and private Host-disk layers so a full page reload does not enter the Remote request queue.

## Publication contract

- Publish `@awiki/dsh-plugin@0.2.5` publicly on the npm `latest` dist-tag while retaining historical release and prerelease tags.
- Keep `awiki:developers` read-write access for the package.
- Merge the reviewed feature branch into `main`, then create a matching non-prerelease GitHub release from that exact commit and attach the exact npm tarball.
- Do not rewrite or delete historical tags or releases.

## Verification contract

- Run the complete package verification and exact-artifact pack checks before publication.
- Exercise group creation, group-history readiness, display-name persistence, optimistic-send reconciliation, local-first history, and all three image-preview cache layers.
- After publication, verify public registry metadata, `latest` and `next` dist-tags, team permission, tarball integrity, a clean public installation, GitHub tag/release target, and release asset digest.
