# dsh-plugin 0.2.0 formal release

## Scope

- Promote the independently installable `@awiki/dsh-plugin` Rust SDK integration from the validated release-candidate line to `0.2.0`.
- Include user-triggered AI conversation summaries, stock-Harness settings support, server-directed OTP cooldown feedback, Enter-to-send behavior, accurate summary stale detection, and the optimistic outgoing-message bubble with its loading indicator.
- Keep the public package identity, Cordis entry points, provider boundaries, runtime-only summary cache, and clean Rust identity cutover unchanged from the validated release candidates.

## Publication contract

- Publish `@awiki/dsh-plugin@0.2.0` publicly on the npm `latest` dist-tag while retaining the historical `next` prerelease tag.
- Keep `awiki:developers` read-write access for the package.
- Create a matching non-prerelease GitHub release from the merged `main` commit and attach the exact verified npm tarball.
- Do not rewrite or delete historical release-candidate tags or releases.

## Verification contract

- Run the complete package verification and dry-run pack before publication.
- Install the exact packed artifact into an empty consumer and import the root, provider, summary-provider, and client exports.
- After publication, verify public registry metadata, `latest` and `next` dist-tags, team permission, tarball integrity, clean public installation, GitHub tag/release target, and release asset digest.
