# dsh-plugin 0.2.1 formal release

## Scope

- Release the conversation-history navigation repair as `@awiki/dsh-plugin@0.2.1`.
- Show loading feedback inside the selected conversation history, then position the view at the newest message after history and attachment previews settle.
- When the reader is away from the bottom, expose the existing down-chevron control; if messages arrive while reading older content, preserve scroll position and show the exact `新消息（N）` count until the reader returns to the latest message.

## Publication contract

- Publish `@awiki/dsh-plugin@0.2.1` publicly on the npm `latest` dist-tag while retaining historical release and prerelease tags.
- Keep `awiki:developers` read-write access for the package.
- Create a matching non-prerelease GitHub release from the merged `main` commit and attach the exact verified npm tarball.
- Do not rewrite or delete historical tags or releases.

## Verification contract

- Run the complete package verification and exact-artifact pack checks before publication.
- Cover history-local loading, initial latest positioning, the no-unread down-chevron state, counted new-message state, click-to-latest behavior, older-history prepends, reduced motion, responsiveness, and accessibility.
- After publication, verify public registry metadata, `latest` and `next` dist-tags, team permission, tarball integrity, a clean public installation, GitHub tag/release target, and release asset digest.
